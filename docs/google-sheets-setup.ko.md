# Google Sheets 연결

현재 계정 기반 버전은 [로그인 업그레이드 안내](login-setup.ko.md)를 함께 진행해야 합니다. 아래 설명은 시트 최초 연결 단계입니다. 기존 시트가 있으면 새로 만들지 마세요.

사이트의 `/google-sheets-setup` 페이지에서 같은 안내와 코드 복사 버튼을 사용할 수 있습니다.

이 코드는 준비된 연결 기능입니다. 실제 Google 계정에서 시트를 만들고 Apps Script 배포를 완료해야 전송됩니다. Google Sheets 문서를 공개할 필요는 없습니다. 점수표의 **공유**에서 선생님 이메일만 뷰어로 추가하세요.

1. https://sheets.new 에서 `ACSL Classroom Scores`를 만듭니다.
2. **확장 프로그램 → Apps Script**를 열고 `public/setup/acsl-google-sheets.gs`를 Code.gs에 붙여넣고 저장합니다.
3. 함수 `setup`을 실행하고 본인의 스프레드시트 접근을 승인합니다. `제출 기록`과 `문제별 결과` 탭이 만들어집니다. 재실행해도 기존 기록을 지우지 않습니다.
4. **프로젝트 설정 → 스크립트 속성**에서 자동 생성된 `ACSL_SHEETS_TOKEN`을 확인합니다. 채팅에 보내지 말고 `.env.local`에만 입력합니다.
5. **배포 → 새 배포 → 웹 앱**에서 실행 사용자를 **나**, 액세스 권한을 **모든 사용자(Anyone)**로 설정합니다. 복사할 주소는 `/exec`로 끝나는 **웹 앱 URL**입니다. `/dev`나 스프레드시트 공유 주소가 아닙니다. 이 웹 앱은 서버 토큰과 검증된 계정으로 요청을 처리합니다. 학생에게는 본인 기록만, 선생님에게는 전체 기록을 반환합니다.
6. Windows 프로젝트에서 `.env.local.example`을 `.env.local`로 복사해 두 값을 입력합니다. 파일 확장자가 `.env.local.txt`가 되지 않게 하세요.
7. 실행 중인 터미널에서 `Ctrl+C`, 이어서 `npm run dev`를 실행합니다. 서버에서만 토큰을 사용하며 `NEXT_PUBLIC_` 접두사를 붙이면 안 됩니다.
8. 선생님이 등록한 학생 Google 계정으로 로그인해 숙제를 제출하고 두 시트의 새 행과 사이트의 저장 완료 메시지를 확인합니다. 설정 존재 확인과 실제 전송 성공은 다릅니다. Google에 쓰기가 확인되기 전에는 저장 완료로 표시하지 않습니다.

## 기록과 재전송

- 제출 기록: 제출 ID, 수신 시각, 학생 제출 시각, 이름, Division, 과제, 점수, 총점, 정답률, 오답 번호.
- 문제별 결과: 제출 ID, 이름, Division, 과제, 문제 번호, 학생 답, 정답, 정오답.
- 시트에서 **데이터 → 필터 보기 만들기**로 선생님마다 학생·Division·과제를 필터링할 수 있습니다.
- 점수는 Next.js 서버가 원본 정답 키로 다시 계산합니다. 브라우저가 보낸 점수를 신뢰하지 않습니다.
- 제출 ID와 Apps Script 잠금을 사용해 중복을 막습니다. 문제별 기록을 먼저 쓰고 제출 요약을 마지막에 쓰므로, 부분 실패 시 재전송하면 빠진 행을 채웁니다.
- 전송 실패 시 답안은 현재 탭에 남습니다. 저장 성공 후 서버가 계산한 점수가 표시됩니다. `같은 답안 다시 전송`을 눌러 재시도하세요. 답안은 현재 탭에만 유지되므로 저장 완료 전에 닫지 마세요.
- Apps Script 코드를 수정한 뒤에는 **배포 관리 → 수정 → 새 버전**으로 배포를 갱신하세요.

## 범위와 문제 해결

Google Sheets/Apps Script는 계정별 사용량 제한 안에서 사용할 수 있으며 별도 유료 호스팅 가입은 필요하지 않습니다. Google Workspace 정책상 외부 웹 앱이 금지되면 관리자의 허용이 필요합니다. 로컬 테스트에 Google Cloud 서비스 계정이나 결제 설정은 필요하지 않습니다.

이 기능은 학생들이 집에서 접속할 사이트 주소를 만들지 않습니다. 현재 사이트를 실행하는 서버에서 Google로 전송하므로, 향후 사이트를 배포할 때도 두 환경변수를 해당 서버에 설정해야 합니다. 학생 개인 컴퓨터에 비밀 토큰을 배포하지 마세요. 학생은 등록된 Google 계정으로 로그인하며 이름은 선생님이 관리합니다.

`Google Sheets is not configured`이면 URL·토큰·파일 이름을 확인하고 서버를 재시작하세요. 전송 확인이 안 되면 Apps Script 배포 권한, `/exec` URL, Script Properties의 토큰 일치, Google 실행 로그와 사용량 제한을 확인하세요. 서버는 상세 원격 오류나 토큰을 브라우저에 노출하지 않습니다.
